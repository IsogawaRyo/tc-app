プライバシーポリシー

TIME CIRCUIT / 最終更新:2026年11月24日

1. このツールについて

TIME CIRCUIT は、開発者本人が自分のために使う個人用のツールです。一般には提供しておらず、利用者は開発者本人だけです。 以下は、本人の Google アカウントのデータを、このツールがどう扱うかの説明です。

2. 利用する Google のデータ

  • Google カレンダーの予定(本人が同期を許可したカレンダーのみ):予定の表示、作成、変更、削除のため
  • カレンダーの一覧(読み取りのみ):同期するカレンダーを本人が選ぶため
  • このツールが作成した Google ドライブのファイル:暗号化したバックアップの保存と整理のため。ドライブにある、それ以外のファイルにはアクセスしません

3. 保存する場所

データは、本人が管理するコンピューターの上にだけ保存します。開発者が運営する外部のサーバーには送りません。 バックアップは、本人のコンピューター上で暗号化してから、本人の Google ドライブに保存します。 復号に使う鍵は、そのコンピューターにも Google ドライブにも置きません。

4. AI アシスタントへの提供

本人が自分で接続した AI アシスタント(例:Anthropic の Claude)が、タスクを提案するために、 予定の題名・日時・場所を読み取ることがあります。予定の説明文と参加者の情報は渡しません。 AI アシスタントは提案を作るだけで、予定やタスクを直接変更することはできません。 この接続は本人の操作で設定・解除でき、本人のデータを本人が使うためだけに行います。

5. 第三者への提供・販売

Google のデータを販売したり、広告に使ったり、上記4の場合を除いて第三者に提供したりすることはありません。 人がデータを読むのは、本人がツールを使うときだけです。

6. Google API サービスのユーザーデータに関するポリシー

TIME CIRCUIT による Google API から取得した情報の使用と他のアプリへの転送は、 限定使用の要件を含め、Google API サービスのユーザーデータに関するポリシーに従います。

7. アクセスの取り消しとデータの削除

Google アカウントのサードパーティのアクセスから、いつでもアクセスを取り消せます。 取り消すと、同期とバックアップは止まります。コンピューター上のデータは本人が削除できます。

8. 連絡先

このページについての連絡は、GitHub から開発者にお寄せください。

Summary in English

TIME CIRCUIT is a personal tool used only by its developer. It accesses the developer's own Google Calendar events (only calendars the developer selects), the calendar list (read-only), and Google Drive files created by the app (encrypted backups). Data is stored only on the developer's own computer; backups are encrypted before being saved to the developer's own Google Drive. An AI assistant connected by the developer may read event titles, times and locations to propose tasks; descriptions and attendees are not shared, and the assistant cannot change data directly. Google user data is never sold, used for advertising, or transferred to others except as described. TIME CIRCUIT's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
